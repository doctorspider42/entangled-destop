-------------------------------------------------------------------------
1. TianoCore EDK2 - the UEFI firmware (artifacts\firmware\CLOUDHV.fd)
-------------------------------------------------------------------------

WHAT IT IS
  A 4 MiB build of EDK2's OvmfPkg/CloudHv/CloudHvX64 package: the UEFI
  firmware a virtual machine starts in, the equivalent of a physical PC's
  BIOS. It is never linked into a host binary. Entangled Desktop reads the
  file and copies it into the virtual machine's memory; the only processor
  that ever executes it is the guest's virtual one.

WHERE IT CAME FROM
  https://github.com/tianocore/edk2, tag edk2-stable202602, built by
  guest/firmware/build-cloudhv.sh with one documented change: the flash
  base PCDs are pointed at 0xFFC00000 so that UEFI variables land in a
  device this virtual machine monitor can back with a file. The exact
  upstream tag, commit, build target and SHA-256 of the shipped image are
  recorded in artifacts\firmware\CLOUDHV.fd.provenance next to it, and the
  digest is also pinned in guest/firmware/pinned.toml.
